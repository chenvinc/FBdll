# 粉笔题目导出插件（FBdll）

> 📦 **最新版本下载**：[FBdll v3.0（插件压缩包）](https://github.com/chenvinc/FBdll/releases/download/v3.0/FBdll-v3.0.zip) ｜ [Release 发布页](https://github.com/chenvinc/FBdll/releases/tag/v3.0)

一个适用于 **粉笔网** 的浏览器扩展（Microsoft Edge / Google Chrome 通用），通过右键菜单，将网页上的题目及解析一键导出为 **JSON**、**TXT** 或 **享道格式** 文件，方便备份、二次整理或导入其他系统。

> 扩展名（manifest）：`网页数据导出`，版本 `3.0`。
> 本项目源码目录名 `FBdll`，核心抓取逻辑位于 `background.js`。

---

## 一、功能说明

### 1. 支持的页面
插件专门解析粉笔网题目页面中的 `.ti-container` 题目容器，兼容两类常见页面结构：

| 页面类型 | 选择器特征 | 识别标识 |
| --- | --- | --- |
| 专项智能练习（旧版） | `article.content` | `v1_专项智能练习` |
| 粉笔题库 - 单页面（新版） | `app-format-html` | `v2_粉笔题库单页面` |

> 只要当前页面上存在题目容器，插件即可工作；若页面未加载完或不是题目页，会提示「未找到任何题目容器」。

### 2. 提取的字段
对每道题目，插件会结构化抽取以下信息：

- **题号 / 题型**（如「1.」「逻辑填空」）
- **所属章节 / 小节**（自动根据锚点 `anchor-ti-*` 或文档顺序推断）
- **题干**：纯文本 `contentText` + 原始 HTML `contentHtml`，自动处理图片占位符 `[IMG1]`、`[IMG2]` …
- **选项**：A/B/C/D 选项文本、HTML、图片、嵌套列表
- **正确答案 / 正确率 / 易错项**
- **解析**：详细解析、考点、来源（来自 `.result-common-section`）
- **图片**：题干 / 选项 / 解析中的图片，区分普通图片与 TeX 公式图（`flag="tex"`），并补全为绝对地址
- **嵌套列表**：保留层级结构
- **诊断信息**（仅 JSON 导出）：提取完整度、置信度、图片统计、分章节汇总、潜在异常题目，便于排查漏抓

### 3. 三种导出格式

| 格式 | 说明 | 适用场景 |
| --- | --- | --- |
| **JSON** | 完整结构化数据，含诊断信息 | 可配合 ALL in ONE Toolbox 软件实现一键导出为 word 格式的题本与解析，并自动下载图片 |
| **TXT** | 人类可读的纯文本 | 直接查看、打印 |
| **享道** | 享道专用排版（题干/选项/考点/答案/解析 + 「本题结束」分隔） | 交付、对接享道格式需求 |

### 4. 使用流程
1. 在题目页面 **右键** → 点击菜单项 **「导出页面数据为JSON」**（菜单文案固定为导出 JSON，实际会再让你选格式）。
2. 弹出 **格式选择框**（JSON / TXT / 享道），点选后「确定」。
3. 弹出 **题目选择框**，可勾选 / 取消、一键「全选 / 反选」，仅导出勾选的题目（导出后自动重新编号）。
4. 点击「导出」，文件自动下载；页面右上角弹出成功 / 失败通知。

> 文件名规则：`<页面标题>_<ISO时间戳>.json|.txt`，非法字符自动替换为 `-` / `_`。

## 二、在 Edge 浏览器中通过开发者模式安装

本插件以「解压缩的扩展（Load unpacked）」形式安装，无需打包、无需上架应用商店。

### 步骤 1：准备插件文件夹
确保以下文件位于**同一个文件夹**内（解压后不要改变目录结构）：

```
FBdll/
├── manifest.json      # 扩展配置（必须）
├── background.js       # 后台 Service Worker（必须）
├── favicon-32x32.png  # 图标
└── readme.md
```

> 安装时请**选择包含 `manifest.json` 的那个文件夹**（即 `FBdll` 目录本身），而不是它的上级目录。

### 步骤 2：打开 Edge 扩展管理页
在 Edge 地址栏输入并回车：

```
edge://extensions
```

或直接点击：`···` 菜单 → **扩展** → 左下角 **管理扩展**。

### 步骤 3：开启「开发人员模式」
在扩展管理页面的 **左下角**，将 **「开发人员模式」** 开关切换为 **开启（On）**。

开启后，页面顶部会出现一排按钮：`打包扩展`、`加载解压缩的扩展`、`导出` 等。

### 步骤 4：加载解压缩的扩展
点击顶部的 **「加载解压缩的扩展 (Load unpacked)」** 按钮，在文件选择器中选中**步骤 1** 中的 `FBdll` 文件夹，点击「选择文件夹」。

加载成功后：
- 扩展列表中会出现名为 **「网页数据导出」** 的条目；
- 若一切正常，状态显示「已启用」，且无红色报错。

### 步骤 5：允许权限（如有提示）
本扩展申请的权限为：`contextMenus`（右键菜单）、`activeTab`、`scripting`。
正常加载后无需额外授权。若 Edge 弹出权限提示，点击「允许」即可。

### 步骤 6：验证安装
1. 访问一个粉笔网题目页面（如题库练习、专项智能练习）。
2. **等待页面完全加载**（题目出现后稍等 1–2 秒）。
3. 在页面任意位置 **右键**，查看菜单中是否出现 **「导出页面数据为JSON」**。
   - 出现 → 安装成功，按「功能说明 - 使用流程」操作即可。
   - 未出现 → 回到 `edge://extensions`，确认该扩展为「已启用」；或点击扩展卡片上的「重新加载 (↻)」按钮重新加载。

## 三、常见问题（FAQ）

**Q1：右键菜单里没有「导出页面数据为JSON」？**
- 确认扩展已启用且处于开发人员模式；
- 在 `edge://extensions` 点击该扩展的「重新加载」图标（圆形箭头）；
- 刷新题目页面后重试。

**Q2：提示「未找到任何题目容器」？**
- 题目页面尚未加载完，请等待题目渲染后再导出；
- 当前页面可能不是粉笔网题库 / 专项练习页面，插件只解析 `.ti-container` 结构。

**Q3：导出的是 JSON，但我想用 TXT / 享道？**
- 右键触发后，第一步的格式选择框即可切换为 TXT 或 享道，无需重新安装。

**Q4：图标显示灰色 / 报错？**
- 检查 `manifest.json`、`background.js` 是否在同一目录且未被改名；
- 打开扩展卡片的「错误」入口查看具体报错并重载。

**Q5：更新插件代码后如何生效？**
- 回到 `edge://extensions`，点击该扩展的「重新加载」按钮即可，无需重复加载文件夹。

## 四、技术说明（简述）

- **Manifest V3**：使用 Service Worker（`background.js`）作为后台；
- 右键菜单 `contextMenus` 触发 → `chrome.scripting.executeScript` 注入页面上下文脚本；
- 抓取逻辑在页面内执行，直接读取 DOM，兼容新旧两套题目结构；
- 下载使用 `Blob` + `Object URL`，不依赖任何外部网络请求，数据全部在本地处理。

## 五、目录结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单：名称、版本、权限、入口 |
| `background.js` | 右键菜单创建、脚本注入、题目解析与导出全流程 |
| `favicon-32x32.png` | 扩展图标 |
| `package.json` | 开发依赖（含 Puppeteer 集成测试脚本，非运行必需） |
| `readme.md` | 本说明文档 |

> 提示：`package.json` 中的 `test:integration` 脚本用于开发者对抓取逻辑的离线测试，普通用户安装使用无需 `npm install`。
